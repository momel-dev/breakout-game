# Breakout Game

A classic Breakout arcade game built with Python and Turtle Graphics.

## Overview

Control the paddle to bounce the ball and break the bricks. Earn points by destroying bricks, and try to complete each stage without losing all your lives.

## Features

* Paddle movement using the left and right arrow keys
* Ball movement and bouncing mechanics
* Brick collision detection and removal
* Score and lives tracking
* Multiple stages with increasing ball speed
* Game Over and Stage Complete notifications

## Technologies

* Python
* Turtle Graphics
* Tkinter

## How to Run

1. Make sure Python 3 is installed.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Run:

   ```bash
   python main.py
   ```

## Controls

| Key         | Action                |
| ----------- | --------------------- |
| Left Arrow  | Move the paddle left  |
| Right Arrow | Move the paddle right |
